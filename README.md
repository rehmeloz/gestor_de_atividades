# 📋 Gestor de Atividades

Sistema de gerenciamento de atividades com operações **CRUD**, desenvolvido com uma arquitetura moderna separando frontend e backend.

## 🚀 Tecnologias Utilizadas

### Frontend
- **React** — Biblioteca para construção da interface de usuário
- **JavaScript (JS)** — Linguagem principal do frontend

### Backend
- **C#** — Linguagem principal da API
- **.NET** — Ecossistema utilizado na API
- **ASP.NET Core** — Framework utilizado na API
- **Entity Framework Core** — ORM utilizado para manipulação de dados da API

## ✨ Funcionalidades

- **CRUD** funcional (Criar, editar, listar e excluir)
